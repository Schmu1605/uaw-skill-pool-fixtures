# Wörter zählen

1. Trenne den Text an Leerraum (Leerzeichen, Tabulator, Zeilenumbruch).
2. Leere Teile zählen nicht; Satzzeichen, die an einem Wort hängen, gehören zum Wort.
3. Antworte mit `Wörter: <Anzahl>`, z. B. für „Das ist ein Test.“ mit `Wörter: 4`.
